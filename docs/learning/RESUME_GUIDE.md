当前仓库可以稳定复现的是自动化回归、本地 Docker 验收和固定 Harness 的流程指标，不是线上模型质量指标。简历最多选择两到三组，避免堆数字：

- 编排消融：32 条 deterministic 用例、三策略共 96 份冻结 Trace；bounded Supervisor 复杂任务 `6/6`，固定单域路由复杂任务 `0/6`，Supervisor 工具集合/参数 exact-match `100%`。
- 本地集成：Docker baseline `19/19`、Redis 故障回源 `18/18`；4 个并发确认请求只有 1 个成功推进本地执行记录。
- 真实模型小样本：8 条 development 固定样本人工复核 `8/8`；平均总 token `1032.5`、平均单次成本约 `$0.00147`、本机 workflow/model p95 `5.24/4.45s`。

可以这样说：

> 我没有把固定用例的通过率叫开放问答准确率。当前真实模型报告只说明 8 条已冻结 development 产物经人工复核通过，并记录了 provider usage、成本和本机延迟；它不代表临床正确率、生产 SLA 或真实用户采纳率。

不能这样说：

- “固定 fixture 的 groundedness/safety 是 100%，所以医疗答案或临床安全率是 100%”；
- “confirmation rate 92.3%，所以人工采纳率 92.3%”；
- “fixture p95 260ms，所以线上响应 260ms”；
- “32 条用例没有暴露某类问题，所以线上不会发生该问题”。
